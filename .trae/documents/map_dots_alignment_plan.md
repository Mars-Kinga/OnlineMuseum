# 地图交互点相对位置修复计划

## 1. 问题分析
当前在 `Desktop.vue` 中，地图上的交互圆点（`.map-dot`）是通过百分比（`left` / `top`）相对于其父容器 `.map-wrapper` 进行定位的。
在此前的修改中，我们将 `.map-wrapper` 的宽度设置为 `max(100vw, calc(100vh * 1440 / 1024))`。
这导致在较宽的屏幕（如 16:9 的桌面端）上，容器的宽度会变为 `100vw`，使得容器的宽高比大于地图原图的宽高比（1440:1024）。
因为 SVG 图片（`<img src="...svg">`）默认会保持自身的宽高比并在容器内居中显示，所以图片实际占据的宽度与容器的宽度不一致。而百分比定位的圆点依然按照 `100vw` 容器的总宽度进行计算，从而导致圆点位置与地图实际画面产生了相对偏移。

## 2. 解决方案
为了让地图缩放时圆点的相对位置始终保持绝对精准，我们需要**强制 `.map-wrapper` 容器严格保持与地图原图完全一致的宽高比（1440 / 1024）**。
- 将 `.map-wrapper` 的宽度直接设置为基于高度计算出的固定比例：`calc(100vh * 1440 / 1024)`。
- 去除 `max(100vw, ...)` 的限制，这样即使在超宽屏幕上，容器和图片的尺寸也会完全吻合，百分比计算将 100% 对齐。
- 为了兼顾宽屏下的视觉效果，给 `.map-wrapper` 添加 `margin: 0 auto;`，使其在屏幕宽度大于地图宽度时水平居中显示。
- 这样既满足了“按照设备网页高度最大化显示”的要求，又完美修复了点位偏移问题。

## 3. 实施步骤
1. 修改 `/src/screens/Desktop.vue` 中的 CSS 样式。
2. 找到 `.map-wrapper` 类，将其 `width` 属性修改为 `calc(100vh * 1440 / 1024)`。
3. 在 `.map-wrapper` 中新增 `margin: 0 auto;` 属性。
4. 保存修改，并通过本地开发服务器预览，缩放浏览器窗口验证交互点是否与地图底图完美贴合不再发生相对移动。
